# Source: RE Motors / ARI PartStream

Entry page:

```text
https://remotors.fi/eng/partfinder
https://remotors.fi/eng/partfinder?aribrand=KTM
```

RE Motors embeds ARI PartStream. The part finder data is rendered by external scripts, not by static HTML generated by RE Motors.

## Observed External Scripts

```text
https://services.arinet.com/PartStream/?appKey=...
https://partstream.arinet.com/Parts/Script?arik=...&ariv=...
https://partstream.arinet.com/ContentManager/Js?arik=...&settings=layout:thumbnail...
https://partstream.arinet.com/ContentManager/Css?arik=...
```

Images are loaded from:

```text
https://cdn.datamanager.arinet.com/image/{brand}/{image_id}/Small
```

The same image id can usually be requested in different sizes, but the exact size variants must be confirmed during implementation.

## Hierarchy

Observed path for KTM:

```text
brand: KTM
year: 2025
model/source node: 125 SX CHASSIS - 2025
assembly: AIR FILTER
diagram: AIR FILTER image + hotspots
parts: ref/OEM/name/price rows
```

DOM attributes:

| Attribute | Meaning |
| --- | --- |
| `arib` | Source brand code, for example `KTM` |
| `aria` | Opaque ARI node id |
| `rel` | `folder` for hierarchy, `assembly` for final groups |
| `slug` | Assembly source path |
| `title` | Display title |

Example year node:

```html
<div title="2025" arib="KTM" aria="FjrcdAkxl-KsENAdRROGDw2" rel="folder" slug="" class="item">
  <p value="2025">2025</p>
</div>
```

Example model/source node:

```html
<li arib="KTM" aria="GZDDNRKn6O8LUxsJsTksvA2" rel="folder" slug="" class="ari-hlvlItem">
  125 SX CHASSIS - 2025
</li>
```

Example assembly node:

```html
<div
  title="AIR FILTER"
  arib="KTM"
  aria="DV9TqbDDXS-lVhCqylBvuA2"
  rel="assembly"
  slug="/KTM/125_SX_CHASSIS_-_2025/AIR_FILTER/7ead2eca-13fc-4fe9-bf0f-a462482059b5/125_SX_CHASSIS_-_2025_AIR_FILTER"
```

## Diagram Hotspots

ARI renders hotspots as absolutely positioned elements over the diagram image.

Observed fields:

- CSS `top`
- CSS `left`
- CSS `width`
- CSS `height`
- class `ariHotSpot`
- sometimes `coords` in attributes

Example:

```html
<div
  class="ariHotSpot"
  style="position: absolute; top: 20px; left: 161px; width: 14px; height: 13px;"
  coords="...">
</div>
```

Store both normalized numeric coordinates and raw attributes.

## Parser Notes

Recommended implementation:

1. Use Playwright for discovery until the underlying ARI request format is fully understood.
2. Store every ARI `arib`, `aria`, `slug`, and browser hash as source provenance.
3. Do not assume ARI ids are stable across app keys or locales without verification.
4. Download diagram images separately in the asset pass.
5. Limit request rate; this is an embedded dealer component.

## Open Research Items
